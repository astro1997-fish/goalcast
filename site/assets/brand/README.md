# GoalCast logo files

| File | Use it for |
| --- | --- |
| `goalcast-logo-dark` | Full logo on dark backgrounds |
| `goalcast-logo-light` | Full logo on white or light backgrounds |
| `goalcast-mark-dark`, `goalcast-mark-light` | The symbol alone, no background |
| `goalcast-icon`, `goalcast-icon-lime` | App icon with rounded corners; the lime one is the browser tab icon |
| `goalcast-profile`, `goalcast-profile-lime` | Square profile pictures for X, Telegram and WhatsApp (safe when cropped to a circle) |

`.svg` files stay sharp at any size; `.png` files are for places that only accept pictures.

Colours: ink `#0c1512`, paper `#f3f7f2`, lime `#b8f04a`, green `#1d7a4a` (replaces lime on light backgrounds).
Lettering: Outfit ExtraBold (SIL Open Font License), converted to shapes so no font is needed.
